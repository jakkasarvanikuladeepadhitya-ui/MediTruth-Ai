About & Safety


How it works: file reading (PDF text, scanned PDF/image via GPT vision, DOCX, TXT) → test extraction (GPT, with rule-based fallback) → range check done in code → evidence check → grounded Q&A → Oracle storage.


Safety: no diagnosis or treatment advice; answers must quote the report; reference ranges come from the report when printed, otherwise generic built-in ranges (or UNKNOWN).
